# dc-cp2-microclips

15-second cuts of the CP2 lower-extremity demos, trimmed to the moment the procedure is
actually performed — about 7 seconds of the final setup, then the end-range / end-feel statement.

26 clips, one per procedure printed on the exam form (the two hip rotations were never filmed).

The anchor is the phrase "end range and end feel". Whisper renders it as **"and range and feel"**,
so the pattern allows both — searching for the correct spelling alone returns zero hits.

Nine procedures share two long source recordings (the ankle and subtalar labs), so the anchor
search is scoped to each procedure's own window, capped at the next procedure's start. Without
that, every procedure in a file resolves to the same timestamp and you ship identical clips.
